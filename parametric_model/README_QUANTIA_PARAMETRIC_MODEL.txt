QUANTIA PARAMETRIC MODEL (QPM)

Este paquete define la verdad editable final del nuevo Reconstruction Core.
No es DXF ni IFC. Es el modelo interno de Quantia.

QPM
├── levels
│   ├── walls PERIMETER (copiados de F02)
│   └── walls DIVIDER (seleccionados por solver global)
├── project_axes
└── extensiones preparadas para openings/spaces/stairs

DXF / IFC / SVG deberán implementarse como adaptadores de publicación.
