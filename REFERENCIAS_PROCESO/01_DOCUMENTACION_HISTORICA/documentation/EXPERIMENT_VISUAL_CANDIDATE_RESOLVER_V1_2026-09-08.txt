OBJETIVO
Comprobar si una sola resolución visual Gemini puede clasificar y agrupar los
candidatos geométricos que Quantia ya descubrió, sin permitir que Gemini invente
coordenadas.

FLUJO
PDF limpio Miguel H
-> F01/F01.5 replay fijo
-> F02
-> Proposal C A1.2 Candidate Discovery
-> imagen compuesta PB+PA:
   izquierda original / derecha todos los candidatos etiquetados
-> UNA invocación lógica Visual Resolver Gemini
-> JSON estructurado por candidate_labels
-> overlay de resultado.

SALIDA GEMINI
- wall_groups[] con candidate_labels existentes
- axis_candidates[]
- dimension_candidates[]
- uncertain_candidates[]

REGLA GEOMÉTRICA
Gemini nunca genera px, líneas nuevas ni IDs nuevos. Solo selecciona etiquetas
existentes; Quantia conserva la geometría original de los candidatos.

PERSISTENCIA
La primera ejecución guarda raw + normalizado + hashes en:
 tests/output/proposal_c_visual_resolver_v1_miguel_h/visual_resolver_history.jsonl
Una ejecución idéntica reutiliza replay y no consume otra llamada.
Para forzar una nueva llamada:
 $env:QUANTIA_VISUAL_RESOLVER_FORCE_CALL="1"
